Tempel Token Admin

Cara menangkap sesi admin tan­pa extension & tanpa Chrome debug. Token tersimpan ke Supabase; daemon otomatis membacanya (≤10 dtk).

  1. Buka halaman admin bandar80 (mis. bandar80.idrbo2.com) dan pastikan sudah login.
  2. Tekan F12 → tab Network → muat/buka fitur riwayat / history scatter.
  3. Klik satu request yang berisi queryTransactionHistoryListForUser lalu buka tab Headers.
  4. Blok semua baris header Request → klik kanan → Copy › Copy request headers.
